# Desktop-Publishing---II-TASK-6
1. Open Adobe Photoshop and create a new document of 1200 × 800 pixels, 300 DPI, RGB Color.
2. Create a background using a dark gradient with purple, blue, and black colors.
3. Import a relevant image, such as a college campus, technology, or event-related photograph, using File → Place Embedded.
4. Rename the image layer to Main Event Image.
5. Use the Select Subject tool or Object Selection Tool to select the main subject.
6. Click Select and Mask to refine the selection, then output the selection with a Layer Mask.
7. Add a new layer named Background Effects and use a custom brush or soft brush to paint glowing particles and light effects.
8. Apply a filter to the background or image using Filter → Blur → Gaussian Blur or Filter Gallery.
9. Add an Adjustment Layer using Layer → New Adjustment Layer → Color Balance to enhance the poster colors.
10. Change the blending mode of the light-effect layer to Screen or Overlay.
11. Add a new text layer and type the event name, for example, TECHNOVA 2026.
12. Use an attractive bold font, such as Bebas Neue, Montserrat ExtraBold, or Anton, for the event title.
13. Apply a Layer Style by double-clicking the title layer and adding Outer Glow, Stroke, or Drop Shadow.
14. Add separate text layers for the event details:
- Date: 25 October 2026
- Time: 10:00 AM – 5:00 PM
- Venue: College Auditorium
- Organizer: Department of Computer Applications
15. Add a small college logo or relevant icons using File → Place Embedded.
16. Create at least three separate layers for the background, event image, and text. Keep all major elements on separate layers.
17. Organize the layers into groups named Background, Main Image, Text, and Effects.
18. Adjust the alignment, spacing, contrast, and typography to create a professional promotional poster.
19. Save the editable file using File → Save As → Photoshop (.PSD).
20. Export the final poster using File → Export → Export As → PNG.
